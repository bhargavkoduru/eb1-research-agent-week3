# Build provenance

This standalone Week 3 repository was split from the original combined project at [commit e47e04f](https://github.com/bhargavkoduru/eb1-policy-desk/tree/e47e04f4686a3551f6e85255c495822cf3945146). The app now opens directly to this week's workflow and the documentation and UI tests are scoped accordingly. Core retrieval and agent behavior is unchanged.

The USCIS corpus, precomputed index and evaluation JSON were copied byte for byte, preserving source hashes and evidence-audit fingerprints. Existing live results were not re-labeled as new runs. Credentials, original PDFs and runtime data were not copied into the repository.

The Week 2 retrieval code, corpus and evaluation remain included as this agent's foundation; the Week 3 submission itself is the research/review/save workflow.
